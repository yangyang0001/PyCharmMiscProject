一个字符，是怎么变成硬盘里的字节的

选一个字符，看它依次经过 ord() 变成 Unicode 码点，再经过 encode('utf-8') 拆成 1~4 个字节 —— 每个字节里，哪几位是"路标"、哪几位是真正的数据，一眼看清。

ASCII
最早的英文字符表，128 个编号就够用。
0 ~ 127
Unicode
给全世界所有文字统一编号的总表。
0 ~ 10FFFF
UTF-8
把 Unicode 编号存成字节的具体规则。
1 ~ 4 字节/字

转换追踪

点选字符，或让它自动播放 —— 观察字节数如何随字符变化。
