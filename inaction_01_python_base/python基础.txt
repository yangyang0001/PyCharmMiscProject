2、字符串 - 原始字符串r 与 三引号多行字符串

r'...'：前缀r表示"原始字符串"(raw string)，字符串里的反斜杠\不会被当作转义字符处理。
例如普通字符串里\n是换行，但r'\n'就是字面上的两个字符\和n。

    s3 = r'Hello, "World!"'
    # 单引号字符串里包含双引号，没有冲突可以直接写；这里没有反斜杠，r前缀没起实际作用
    # 结果：Hello, "World!"

'''...'''：三个引号表示可以写多行字符串，中间的换行会被保留在字符串内容里。

    s4 = r'''Hello,
    World!'''
    # 结果是一个包含真实换行符的字符串，等价于 'Hello, \nWorld!'
    # 这里的换行是敲的回车，是真实换行，不是转义符\n，所以加不加r都一样

总结：r只在字符串里出现\时才有意义（避免转义）；三引号只是为了让字符串能跨多行写、不用手动加\n。
