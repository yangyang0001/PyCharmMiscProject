Jupyter Notebook 快捷键
==============================

Jupyter 有两种模式:
  - 命令模式 (Command Mode): 单元格左侧为蓝色, 按 Esc 进入, 对单元格整体操作
  - 编辑模式 (Edit Mode):    单元格左侧为绿色, 按 Enter 进入, 在单元格内编辑代码/文本

注: Mac 下 Ctrl 对应 Cmd, Alt 对应 Option


一、通用 (两种模式均可用)
------------------------------
Shift + Enter      运行当前单元格, 并选中下一个单元格 (没有则新建)
Ctrl + Enter       运行当前单元格, 停留在当前单元格
Alt + Enter        运行当前单元格, 并在下方插入新单元格
Ctrl + S           保存 Notebook
Ctrl + Shift + P   打开命令面板 (搜索所有命令)


二、命令模式 (先按 Esc)
------------------------------
Enter              进入编辑模式
H                  显示快捷键帮助

-- 单元格类型 --
Y                  切换为代码单元格 (Code)
M                  切换为 Markdown 单元格
R                  切换为原始文本单元格 (Raw)
1 ~ 6              切换为 Markdown 1~6 级标题

-- 插入 / 删除 --
A                  在上方插入单元格 (Above)
B                  在下方插入单元格 (Below)
D, D               删除当前单元格 (连按两次 D)
Z                  撤销删除单元格

-- 复制 / 剪切 / 粘贴 --
C                  复制单元格
X                  剪切单元格
V                  粘贴到下方
Shift + V          粘贴到上方
Shift + M          合并选中的单元格 (多个时) / 与下方单元格合并

-- 选择 / 移动 --
↑ 或 K             选中上一个单元格
↓ 或 J             选中下一个单元格
Shift + ↑ / ↓      向上 / 向下扩展选择多个单元格
Ctrl + A           选中所有单元格

-- 显示 --
L                  显示 / 隐藏当前单元格行号
Shift + L          显示 / 隐藏所有单元格行号
O                  显示 / 隐藏输出
Shift + O          切换输出滚动

-- 内核 (Kernel) --
I, I               中断内核 (连按两次 I, 如停止死循环)
0, 0               重启内核 (连按两次 0)

-- 其他 --
S                  保存
F                  查找与替换
Space              向下滚动
Shift + Space      向上滚动


三、编辑模式 (按 Enter 进入)
------------------------------
Esc                退出到命令模式
Tab                代码补全 / 缩进
Shift + Tab        查看函数签名与文档 (连按多次显示更详细)
Ctrl + ]           增加缩进
Ctrl + [           减少缩进
Ctrl + /           注释 / 取消注释选中行
Ctrl + A           全选单元格内内容
Ctrl + Z           撤销
Ctrl + Shift + Z   重做 (部分版本为 Ctrl + Y)
Ctrl + Home        跳到单元格开头
Ctrl + End         跳到单元格末尾
Ctrl + ← / →       按单词左右移动光标
Ctrl + Backspace   删除前一个单词
Ctrl + Delete      删除后一个单词
Ctrl + Shift + -   在光标处拆分单元格
Alt + 鼠标拖动     多列 (矩形) 选择
Ctrl + 鼠标点击    多光标编辑


四、常用魔法命令 (在代码单元格中输入)
------------------------------
%time 语句         统计单条语句运行时间
%timeit 语句       多次运行取平均时间
%%time             统计整个单元格运行时间 (放在单元格第一行)
%run xxx.py        运行外部 Python 文件
%pwd               显示当前工作目录
%ls                列出当前目录文件
%who / %whos       查看当前定义的变量
%reset             清除所有变量
%matplotlib inline 在 Notebook 中内嵌显示图表
!命令              执行系统命令, 如 !pip install requests
函数名?            查看帮助文档, 如 print?
函数名??           查看源码


五、最常用 TOP 10
------------------------------
Shift + Enter   运行并下移
Esc / Enter     切换命令 / 编辑模式
A / B           上方 / 下方插入单元格
D, D            删除单元格
Z               撤销删除
M / Y           切换 Markdown / 代码
Shift + Tab     查看函数文档
Tab             代码补全
Ctrl + /        注释
0, 0            重启内核
