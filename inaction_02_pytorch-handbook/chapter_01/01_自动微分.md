# 自动微分（Autograd）

## 一句话定义

**Autograd** 是 PyTorch 自动计算梯度的引擎。只要给张量打开 `requires_grad=True`，PyTorch 就会在运算过程中悄悄记录下"这个张量是怎么算出来的"，最后调用一次 `.backward()`，就能自动把梯度沿着这条记录反向传播回去，不需要手写任何求导公式。

> 关于 `.backward()` 里传入的向量 `v`（gradients 参数）到底是什么、vector-Jacobian product 的完整数学推导，见 [00_范数和雅可比矩阵求导.md](./00_范数和雅可比矩阵求导.md)，本文只做结论性使用，不重复推导。

## 核心概念：Tensor 与计算图

| 属性/方法 | 含义 | 使用范围 | 叶子节点或非叶子节点 |
|---|---|---|---|
| `.requires_grad` | 这个张量是否需要被 autograd 追踪 | 所有张量都可读写 | 叶子节点 / 非叶子节点均可 |
| `.grad_fn` | 记录"这个张量是由哪个运算产生的"，构成计算图的边；用户直接创建的张量该属性为 `None` | 所有张量都有该属性（只读） | 叶子节点为 `None`；非叶子节点才有实际值 |
| `.is_leaf` | 是否是**叶子节点**（用户直接创建，不是运算结果） | 所有张量都有该属性（只读） | 叶子节点 / 非叶子节点均可 |
| `.grad` | 反向传播算出来的梯度值；默认只有叶子节点会保留 | `backward()` 之后读取 | 默认只有叶子节点会保留；非叶子节点需先 `retain_grad()` |
| `.requires_grad_(True)` | 就地（in-place）修改一个已存在张量的 `requires_grad` | 运算之前调用 | 仅限叶子节点（对非叶子节点调用会报错） |
| `.retain_grad()` | 让非叶子节点也保留 `.grad`（否则反向传播后会被释放） | `backward()` 之前调用 | 仅用于非叶子节点（叶子节点默认已保留，无需调用） |

## 从叶子节点到计算图：逐步演示

```python
import torch

x = torch.ones(2, 2, requires_grad=True)
print(x)
# tensor([[1., 1.],
#         [1., 1.]], requires_grad=True)
```

`x` 是用户直接创建的，`x.is_leaf == True`，`x.grad_fn is None`。

```python
y = x + 2
print(y)
# tensor([[3., 3.],
#         [3., 3.]], grad_fn=<AddBackward0>)

print(y.grad_fn)
# <AddBackward0 object at 0x10d829e70>
```

`y` 是加法运算的结果，`y.is_leaf == False`，`y.grad_fn` 记录了"这是一次加法产生的"——这正是计算图的一条边。

```python
z = y * y * 3
out = z.mean()

print(z)
# tensor([[27., 27.],
#         [27., 27.]], grad_fn=<MulBackward0>)

print(out)
# tensor(27., grad_fn=<MeanBackward0>)
```

到这里就形成了一条完整的计算图链：$x \to y \to z \to \text{out}$，每一步的 `grad_fn` 名字都对应着产生它的运算（`Add` / `Mul` / `Mean`）。

## 手动开启 requires_grad

`requires_grad` 默认是 `False`，可以用 `.requires_grad_()`（注意下划线结尾，就地修改）随时打开：

```python
a = torch.randn(2, 2)
a = ((a * 3) / (a - 1))
print(a.requires_grad)   # False

a.requires_grad_(True)
print(a.requires_grad)   # True

b = (a * a).sum()
print(b.grad_fn)   # <SumBackward0 object at 0x10d1fc610>
```

只要在某次运算**之前**把 `requires_grad` 打开，之后由它参与产生的所有张量都会自动被追踪进计算图。

## 反向传播：backward()

对一个**标量**调用 `.backward()`，PyTorch 会自动补上 $v=1$（等价于假设 $\text{out}$ 就是最终的下游标量本身），沿着计算图反向传播：

```python
out.backward()
```

## 只有叶子节点默认会保留梯度

```python
print(x.grad)
# tensor([[4.5000, 4.5000],
#         [4.5000, 4.5000]])

print(x.is_leaf)     # True
print(y.grad_fn)     # <AddBackward0 object at ...>

print(y.grad)   # None，并触发 UserWarning
print(z.grad)   # None，并触发 UserWarning
print(out.grad) # None，并触发 UserWarning
```

访问非叶子节点的 `.grad` 会得到 `UserWarning`：

```
UserWarning: The .grad attribute of a Tensor that is not a leaf Tensor is being accessed.
Its .grad attribute won't be populated during autograd.backward().
If you indeed want the .grad field to be populated for a non-leaf Tensor,
use .retain_grad() on the non-leaf Tensor.
```

也就是说：**默认情况下 PyTorch 只给叶子节点保留梯度**（省显存），如果想让中间节点也保留，必须在 `backward()` 之前显式调用 `retain_grad()`：

```python
x.retain_grad()
y.retain_grad()
z.retain_grad()
```

| 张量 | is_leaf | grad_fn | 默认反向传播后 `.grad` |
|---|---|---|---|
| `x` | `True` | `None` | 有值（叶子节点 + `requires_grad=True`） |
| `y` | `False` | `AddBackward0` | `None`（除非 `retain_grad()`） |
| `z` | `False` | `MulBackward0` | `None`（除非 `retain_grad()`） |
| `out` | `False` | `MeanBackward0` | `None`（除非 `retain_grad()`） |

## 手动验证：x.grad 是怎么算出来的

$$
\text{out} = \text{mean}(z) = \text{mean}(3y^2) = \text{mean}\big(3(x+2)^2\big)
$$

$z$ 是形状 $(2,2)$ 的张量，`mean()` 对4个元素取平均，所以：

$$
\frac{\partial\,\text{out}}{\partial x_i} = \frac{1}{4}\cdot 6\,(x_i+2) = 1.5\,(x_i+2)
$$

代入 $x_i=1$：

$$
1.5 \times (1+2) = 4.5
$$

正好对应 `x.grad` 里每个位置都是 `4.5`。

## dtype 在计算图里保持不变

```python
print(x.dtype, y.dtype, z.dtype, out.dtype)
# torch.float32 torch.float32 torch.float32 torch.float32
```

计算图上各个节点的 dtype 会跟随最初创建时的 dtype 传递下去，运算不会偷偷改变精度（除非显式 `.float()` / `.double()` 转换）。

## 非标量输出：手动传入 gradients

当输出不是标量时（比如例子里的 `z`），必须手动传入和输出形状相同的 `gradients` 参数（即 $v=\partial\text{out}/\partial z$），否则 `backward()` 会报错：

```python
x = torch.randint(1, 10, size=(3,), dtype=torch.float, requires_grad=True)
# tensor([8., 3., 7.], requires_grad=True)

y = x * 3
while y.data.norm() < 1000:
    y = y * 3
# tensor([1944., 729., 1701.], grad_fn=<MulBackward0>)

y.backward(torch.tensor([1.0, 2.0, 3.0]))
print(x.grad)
```

这里 `y` 由 `x` 逐元素乘以同一个标量若干次得到，雅可比矩阵仍然是对角阵，`gradients` 必须和 `y` 同形状（长度3）——形状约束、`v` 的具体含义、以及为什么不能直接用 `y` 的数值代替 `gradients`，详见 [00_范数和雅可比矩阵求导.md](./00_范数和雅可比矩阵求导.md) 中的完整推导。
