# 范数（Norm）

## 一句话定义

**范数**是衡量向量"大小/长度"的一种标准化方法。给定一个向量，范数把它映射成一个**非负实数**，这个数表示这个向量有多"大"。

数学记号：$\|x\|$，读作 "x 的范数"。

## 严格数学定义

设 $V$ 是一个向量空间（比如 $\mathbb{R}^n$）。**范数**是一个函数：

$$
\|\cdot\| : V \rightarrow \mathbb{R}_{\geq 0}
$$

即：把向量空间 $V$ 中的任意一个向量 $x$，映射到一个**非负实数** $\|x\|$，并且这个函数必须同时满足下面三条公理（缺一不可，否则不能叫"范数"）。

## 范数必须满足的三条性质

不是随便一个能算出数字的公式都能叫"范数"，必须同时满足：

1. **非负性**：$\|x\| \geq 0$，且 $\|x\| = 0 \iff x = 0$（只有零向量的范数才是0）
2. **齐次性（数乘）**：$\|\alpha x\| = |\alpha| \cdot \|x\|$（向量放大 α 倍，范数也放大 |α| 倍）
3. **三角不等式**：$\|x + y\| \leq \|x\| + \|y\|$（两边之和大于等于第三边，几何直觉）

## 常见的范数类型（Lp 范数家族）

对向量 $x = (x_1, x_2, \dots, x_n)$，**Lp 范数**定义为：

$$
\|x\|_p = \left( \sum_{i=1}^{n} |x_i|^p \right)^{1/p}
$$

### L1 范数（p=1）—— 曼哈顿范数

$$
\|x\|_1 = \sum_i |x_i|
$$

几何意义：像城市街区里从A点走到B点，只能沿着横平竖直的街道走，不能走对角线。

```python
import torch
x = torch.tensor([3.0, -4.0])
x.norm(p=1)   # |3| + |-4| = 7
```

### L2 范数（p=2）—— 欧几里得范数（默认）

$$
\|x\|_2 = \sqrt{\sum_i x_i^2}
$$

几何意义：两点间的直线距离（勾股定理）。这是**最常用**的范数，PyTorch 的 `.norm()` 默认就是它。

```python
x = torch.tensor([3.0, 4.0])
x.norm()        # 默认 p=2: sqrt(3^2+4^2) = sqrt(25) = 5
x.norm(p=2)     # 等价写法
```

### L∞ 范数（无穷范数）—— 取最大绝对值

$$
\|x\|_\infty = \max_i |x_i|
$$

```python
x = torch.tensor([3.0, -4.0, 1.0])
x.norm(p=float('inf'))   # max(|3|, |-4|, |1|) = 4
```

## 为什么深度学习里经常用到范数

| 用途 | 说明 |
|---|---|
| 衡量向量/梯度的大小 | 比如判断梯度是否爆炸（gradient explosion），常看梯度的 L2 范数 |
| 梯度裁剪（gradient clipping） | `torch.nn.utils.clip_grad_norm_()` 就是把梯度的范数限制在某个阈值以内 |
| 正则化（regularization） | L1 正则（产生稀疏解）、L2 正则（权重衰减 weight decay）本质就是在 loss 里加上权重的范数作为惩罚项 |
| 归一化（normalize） | 把向量除以自己的范数，得到长度为1的"单位向量"，只保留方向信息 |
| 衡量误差 | 比如两个向量的距离 $\|a - b\|_2$，常用来衡量预测值和真实值的差距 |

## norm() 和标准差（std）的区别

容易混淆的两个概念：

$$
\|x\|_2 = \sqrt{\sum_i x_i^2} \qquad \text{（不减均值，衡量离原点的距离）}
$$

$$
\text{std} = \sqrt{\frac{1}{n}\sum_i (x_i - \bar{x})^2} \qquad \text{（先减均值，衡量数据的离散程度）}
$$

给向量整体加一个常数（平移），`norm()` 的结果会剧烈变化，但 `std()` 不变——因为 norm 关心"离原点多远"，std 关心"数据彼此之间波动多大"。

## 矩阵也有范数

范数不仅适用于向量，也适用于矩阵，比如 Frobenius 范数（矩阵版的 L2 范数，把矩阵展平成向量再算）：

```python
A = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
A.norm()   # 默认按 Frobenius 范数: sqrt(1^2+2^2+3^2+4^2) = sqrt(30)
```

## 词源小知识

"norm" 来自拉丁语 **norma**（标准、规范、直角尺），数学中借用表示"衡量向量大小的标准化定义"。归一化 **normalize** 就是这个词的动词形式——把向量除以自己的范数，变成"标准长度（1）"的向量。

## 附录：`norm(p=float('inf'))` 里用到的 Python 特殊值

计算 L∞ 范数时用到了 `float('inf')`，顺带记录一下 Python 里类似的"特殊值"都有哪些。

### 1. IEEE 754 浮点数的特殊值（`float` 类型专属）

| 特殊值 | 写法 | 含义 |
|---|---|---|
| 正无穷 | `float('inf')` 或 `math.inf` | 比任何有限数都大 |
| 负无穷 | `float('-inf')` 或 `-math.inf` | 比任何有限数都小 |
| NaN（非数） | `float('nan')` 或 `math.nan` | 未定义运算结果，如 `0/0`、`inf - inf` |
| 正零 | `0.0` | 一般意义上的0 |
| 负零 | `-0.0` | 数值上等于0.0，但符号位不同（IEEE754底层区分） |

严格来说只有 **3 种"非正常数值"**：`inf`、`-inf`、`nan`，这是 IEEE 754 标准强制要求任何浮点数实现都要支持的。

### 2. Python 语言层面的内置常量（Built-in Constants）

Python 官方文档 "Built-in Constants" 里列出的、语言级别的特殊常量，一共 **6 个**：

| 值 | 类型 | 含义 |
|---|---|---|
| `True` | `bool` | 布尔真值，本质是 `int` 的子类（`True == 1`） |
| `False` | `bool` | 布尔假值，本质是 `int` 的子类（`False == 0`） |
| `None` | `NoneType` | 表示"没有值"，全局唯一，只有一个实例 |
| `NotImplemented` | `NotImplementedType` | 运算符重载（如 `__eq__`、`__add__`）中表示"这个操作没实现，请对方或Python尝试别的方式" |
| `Ellipsis`（即 `...`） | `EllipsisType` | 常用于类型标注占位、NumPy/PyTorch 多维切片（如 `x[..., 0]`） |
| `__debug__` | `bool` | 正常运行时是 `True`；用 `python -O` 优化模式启动时是 `False`，此时 `assert` 语句会被跳过 |

其中 `True`、`False`、`None`、`NotImplemented`、`Ellipsis` 都是**单例（singleton）**——整个 Python 进程里各自只存在一个实例，所以判断时惯例用 `is`（比如 `x is None`），而不是 `==`。

### 3. 数值边界常量（不算"特殊值"，但常一起用到）

这些不是"特殊值"本身，而是描述数值系统边界的**普通数字**，容易和上面的特殊值混着用：

| 值 | 来源 | 含义 |
|---|---|---|
| `math.pi` | `math` 模块 | 圆周率 π |
| `math.e` | `math` 模块 | 自然常数 e |
| `math.tau` | `math` 模块 | 2π |
| `sys.maxsize` | `sys` 模块 | 平台上 `Py_ssize_t` 能表示的最大值（约等于 int 索引上限，不是"整数最大值"，Python int 本身无上限） |
| `sys.float_info.max` | `sys` 模块 | 浮点数能表示的最大有限值，超过就变成 `inf` |
| `sys.float_info.min` | `sys` 模块 | 浮点数能表示的最小正规数 |

### 判断函数

```python
import math

math.isinf(float('inf'))   # True
math.isnan(float('nan'))   # True
x is None                    # 判断是否为 None，推荐写法
```
