PyTorch · LeNet-5 · torch.nn

一张网络里的两种"计算"

__init__ 只在创建网络时算一次层的形状； forward 每次调用都要重新把张量形状推一遍、重新建一次动态图。下面把这两种计算分开画。

对应 03_neural_networks.ipynb / 03_神经网络.md 第2、4、5节

① 构建阶段

__init__ · 只跑一次

五个带参数的层在这里被依次创建：构造参数直接决定权重/偏置的形状；nn.Module 重写过的 __setattr__ 会把它们自动注册进 net._modules； 随后 PyTorch 用 kaiming_uniform_ 给权重和偏置填上初始随机值——这三件事，才是"创建网络"时真正发生的全部计算。

② 前向阶段

forward · 每次 net(input) 都重新执行

数据从输入一路流过 conv → relu → pool → conv → relu → pool → flatten → fc → relu → fc → relu → fc。 点击任意一步，或用下面的控件播放，看形状如何被一步步推导出来。
